# 虚拟生态环境

许多游戏都想要在游戏世界里面实现某种程度的生态环境，以便体现自己的某种拟真程度
这在怪物猎人，宝可梦当中都有体现
我在玩everything is crab的时候也觉得挺有意思
但是当洛克王国世界出现的时候，全世界都在称赞其生态和互动设计的时候，我却感觉到无趣和厌恶了
那么，到底什么是生态，怎么才能形成这样的生态呢？

## 洛克王国

我在游玩洛克王国的过程并没有感受到所谓生态的内容，但是骑乘系统的体验相对较好
后续看到网络上的各种分享互动与生态的内容，我却仅仅只觉得这是给每个精灵设计的动作以及对应触发条件而已，本质上是大量的列表，是工作量的叠加，没有很精妙的设计在里面

为什么我会有这样的感受呢？为什么我在everything is crab里面就觉得这种动作和触发条件的堆叠更有意思得多呢？

我简单思考出几个原因：
我在玩洛克王国的时候，任务和审视感更重，而体验感弱，导致我快速进入了拆解阶段而非感受阶段
游玩时候因为需要跟上身边朋友的进度，所以我需要快速体验内容，这与我感受游戏内容的方式不同，于是形成了走马观花之感。我没有对游戏世界与其构成的理由有深入的了解，当我后续想要寻找一个深入了解的渠道时，却也发现没有这样一个显而易见的入口，所以我常常抨击洛克王国的剧情很差。

但我现在看来，洛克王国无疑是成功的
首先它设计相当合理有趣的 PVP 内容，是主打的游戏方法，而且是长时间的终极游戏内容。或许 PVP 与 PVE 内容的失衡并非缺陷，而是刻意的宣发手法。
而在喜欢可爱精灵并与之互动的玩家中，则有大世界，换装，社交的元素进行填充，并且针对国内精灵互动游戏的蓝海，采取了堆料式的开发方法，十分讨巧。
扬长避短非常成功，简直可以称之为营销与内容排期的典范。

但是它的剧情也是实打实不行，作为世界的基底，它没有完善补充所谓生态的系统涌现感，没能把我从单点互动丰富度这一感觉上升到生态系统。洛克王国的关注点奇妙地分散，以至于剧情没能形成内在统一感，于是在我眼里所谓奇妙生态就成了可爱或有趣互动的堆料。
但这也许也是延续童年 IP 这一需求下的取舍，听说三测的时候剧情还是黑深残风格，然后听取玩家建议更改称为了现有的童趣轻松风，也许就因此抛弃了部分剧情与世界感的铺垫。
当然这也是我一厢情愿的想象，想象洛克王国原有的项目组希望能够描述一个完整有趣的世界，只是从商业角度上放弃了这一点。但是无论怎么说，按照这样的分析结果来看，制作组里都有高人
