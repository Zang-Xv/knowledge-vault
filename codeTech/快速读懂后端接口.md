# 怎么快速阅读后端代码

代码的抽象和层级相当多
怎么快速阅读代码才可以理清层次并达到可用地步呢?
我现在简直是代码阅读苦手

## 阅读流程

要快速读懂 Flask 接口代码，核心不是逐行看，而是用一个固定的阅读框架拆解它。
示例代码

```py
@app.route('/setting1',methods=['GET', 'POST'])
def setting_preview_wc():
    clear_folder()
    print(request.get_json())
    data = request.get_json()
    chart_type = data["chart-type"]
    aspect_ratio = data["aspect-ratio"]
    bar_width = data["bar_width"]
    chart_data = data["data"]
    try:
        y_min = data["y_min"]
        y_max = data["y_max"]
    except:
        pass
    chart_json = json.loads(chart_data)

    # get shuju
    x = chart_json["x"]
    y = chart_json["y"]
    title = chart_json["title"]
    if chart_type == "scatter":
        z = chart_json["z"]
        # z = []

    # user defined data
    aspect_ratio_fronend = ['1:1', '3:2', '4:3', '5:4']
    ratio_id = aspect_ratio_fronend.index(aspect_ratio)
    aspect_ratio = [(5,5), (5.5,3.7), (4, 3), (5, 4)]
    global figure_size
    figure_size = aspect_ratio[ratio_id]
    print("====================================")
    print("figure_size: ", figure_size)
    if "y_min" in locals() and "y_max" in locals():
        # 使用 y_min 变量
        print(y_min, y_max)
        y_limit = (y_min, y_max)
    else:
        y_limit = None # (-3, 50)

    print("aspect_ratio[ratio_id]: ", aspect_ratio[ratio_id])
    if chart_type=="bar":
        img_path1 = table2img_bar(x, y, aspect_ratio[ratio_id], title, y_limit, bar_width)
        _, mask_path_foreground, mask_path_background = img2mask_bar(x, y, aspect_ratio[ratio_id], y_limit, bar_width)
    if chart_type == "line":
        img_path1, pos_pix, fig_size, xy_corners_pix = table2img_line(x, y, aspect_ratio[ratio_id], title, y_limit, four_corners = None)
        mask_path_foreground, mask_path_background = img2mask_line(pos_pix, fig_size, xy_corners_pix, y_limit)
    if chart_type == "pie":
        img_path1 = table2img_pie(y, x, aspect_ratio[ratio_id], title)
        mask_path_foreground, mask_path_background = img2mask_pie(y, x, aspect_ratio[ratio_id])
    if chart_type == "scatter":
        img_path1 = table2img_scatter(x, y, z, title, y_limit, aspect_ratio[ratio_id])
        mask_path_foreground, mask_path_background = img2mask_scatter(x, y, z, y_limit, aspect_ratio[ratio_id])
    d = extract_kw_similar(title)
    wordcloud_gen = WordCloudGenerator(font_path='/home/ubuntu/ChartSpark/frontend/src/assets/fonts/TiltNeon-Regular.ttf',  
                                    background_color='#F5F5F5', colormap="binary",  
                                    prefer_horizontal=1, 
                                    max_font_size=45, min_font_size=12, 
                                    width=420, height=200, 
                                    margin=50, d=d)
    img_path2 = wordcloud_gen.generate_wordcloud()
    return [img_path1, img_path2, mask_path_foreground, mask_path_background]
```

### 第一步：确认接口的「入口信息」

```py
@app.route('/setting1',methods=['GET', 'POST'])
    def setting_preview_wc():
```

只需要看三件事：

| 信息      | 含义         |
| --------- | ------------ |
| /setting1 | 接口路径     |
| GET, POST | 支持的方法   |
| 函数名    | 实际执行逻辑 |

这个接口是：`POST /setting1` , 大概率是前端发送 JSON 数据。

### 第二步：看输入数据结构（最重要）

`data = request.get_json()`说明这是一个 JSON 接口。

继续往下看：

```python
chart_type = data["chart-type"]
aspect_ratio = data["aspect-ratio"]
bar_width = data["bar_width"]
chart_data = data["data"]
```

你现在就能反推出前端必须传：

```json
{
  "chart-type": "...",
  "aspect-ratio": "...",
  "bar_width": ...,
  "data": "...",
  "y_min": ...,
  "y_max": ...
}
```

再往下：

```py
chart_json = json.loads(chart_data)
x = chart_json["x"]
y = chart_json["y"]
title = chart_json["title"]
```

说明：

`data["data"]` 里面其实又是一个 JSON 字符串。
所以完整输入结构是：

```json
{
  "chart-type": "bar",
  "aspect-ratio": "4:3",
  "bar_width": 0.8,
  "data": "{\"x\": [...], \"y\": [...], \"title\": \"xxx\"}"
}
```

到这里你已经理解了 50%。

### 第三步：找“分支核心逻辑”

看这个：

```py
if chart_type=="bar":
if chart_type=="line":
if chart_type=="pie":
if chart_type=="scatter":
```

说明：这是一个“图表分发器”。

核心结构是：
前端给 chart_type
后端根据类型调用不同的生成函数

### 接口真正干了什么？

你可以抽象成三步：

1. 生成图像
例如：`img_path1 = table2img_bar(...)`
说明它：
把表格数据 → 转换成图片

2. 生成 mask
mask_path_foreground
mask_path_background
说明它：`生成前景/背景掩码`
（大概率给后续 AI 或图像处理用）

3. 生成词云

    ```py
    wordcloud_gen = WordCloudGenerator(...)
    img_path2 = wordcloud_gen.generate_wordcloud()
    ```

    说明：根据标题 → 抽关键词 → 生成词云图片

### 最后返回什么？

`return [img_path1, img_path2, mask_path_foreground, mask_path_background]`

返回：

```code
[
  图表图片路径,
  词云图片路径,
  前景mask路径,
  背景mask路径
]
```

所以这是一个：图表生成 + mask生成 + 词云生成接口

### 总结: 快速读 Flask 接口的通用方法

以后你读任何 Flask 接口，用这个顺序：

- 看 route
- 看 request 获取方式
- 推输入 JSON 结构
- 找 if 分支
- 找调用的核心函数
- 看 return

不要陷入细节

## 绘制数据流图

具体怎么绘制规范好用的数据流图或者uml呢?

### 第一步：只画「输入 → 输出」

先完全不看细节。

```text
POST /setting1
        ↓
   JSON数据
        ↓
   返回 4 个图片路径
```

先写：
输入: chart_type, aspect_ratio, bar_width, data, y_min?, y_max?
输出: [img_path1, img_path2, mask_fg, mask_bg]

### 第二步：拆成 3 个阶段

观察代码可以发现它做了三件事：

1. 解析数据
2. 生成图表和mask
3. 生成词云

画成：

```text
JSON
  ↓
数据解析
  ↓
图表生成 + mask生成
  ↓
词云生成
  ↓
返回路径
```

到这里你已经有整体结构。

### 第三步：加入“分支逻辑”

这里是接口核心：

if chart_type=="bar":
if chart_type=="line":
if chart_type=="pie":
if chart_type=="scatter":

所以你画成：

```text
                 ┌── bar ───── table2img_bar
                 │
JSON → 分发器 ───┼── line ─── table2img_line
                 │
                 ├── pie ──── table2img_pie
                 │
                 └── scatter ─ table2img_scatter
```

这一步完成，你已经理解 80%。

### 第四步：把完整数据流画出来

最终你应该能画成这样（文字版）：

客户端
  ↓ POST /setting1
Flask接口
  ↓
request.get_json()
  ↓
解析 data / chart_type / ratio
  ↓
计算 figure_size / y_limit
  ↓
根据 chart_type 分发
  ↓
table2img_xxx → 生成图表图片
  ↓
img2mask_xxx → 生成前景背景mask
  ↓
extract_kw_similar → 提取关键词
  ↓
WordCloudGenerator → 生成词云
  ↓
return [图表路径, 词云路径, mask_fg, mask_bg]
