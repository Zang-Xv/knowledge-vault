## 架子鼓基础介绍

常用的三个模块分别是：底鼓 Bass Drum（动），踩镲 Hi-Hat（次），军鼓 Snare Drum（打）
底鼓就是右脚踩的那个很大声的打鼓
踩镲则是因为用脚控制开闭有不同声音，所以取名叫做踩镲吧
军鼓则是摆在你面前的那个小鼓

剩下其他的模块为嗵鼓 Tom-Tom，吊镲 Crash Cymbal（强音镲），叮叮镲 Ride Cymbal（节奏镲）
嗵鼓分大中小三个，吊镲则左右各一个
所以合起来总共有**五鼓四镲**，是一个常规爵士鼓组，也是现代架子鼓的通用配置，可以适配各种类型的曲目

### 电鼓和原声鼓的区别

电鼓在动态和力度控制上是无法和原生鼓相比的
但是鉴于住房的噪音问题，电鼓还是十分必要的

虽然不能够使用电鼓练习力度控制，但是作为玩具而言是足够的了

而且电鼓还能拿来玩 DrumMania，美滋滋了
改一改说不定还能玩太鼓达人

## 电子鼓挑选准则

动态：音源根据信号来源、信号值的大小（力度）来播放对应音色且力度对等的采样文件。采样力度分层越多，动态越好。

音色：录制的采样文件，够听即可。

音源：鼓组上的小盒子。一般有罗兰（roland），法国追梦（dream）
追梦是一个电子乐器打包解决方案提供商，许多厂商都是使用dream二次研发的音源

### 其他看点

独立镲架：手感和镲片摇晃会更加接近原生鼓，也可以提供更多的位置调整自由度。和分体式踩镲触发器对应。

双触发：面和边触发的采样不同，可以更好模拟原生鼓的动态。更高级的还有三触发，例如镲片的镲帽也有触发区域，可以打出叮叮声。

多点侦测：比双触发更加高级，能够实现更加连续的打击点检测

网面：更好的回弹更好的击打手感

轻音边击：鼓棒横跨整个鼓面，鼓棒末端放在鼓面上，敲击鼓边

重音边击：类似正常的击打手势，但是压低手肘，同时用力打中鼓边和鼓面

止音：按住鼓或者镲停止震动来消除声音

Hi-Hat Splash：用左脚控制踩镲开合，通过镲片碰撞发出声音。电鼓需要检测开合速度和开合距离来判断是否 splash。

### 二手电鼓老化问题

停产较久的款式鼓的触发器可能会老化，其中的海绵锥触发器老化后会导致力度感知。
老化的海绵锥变硬厚，失去缓冲能力，鼓棒打击力度将直接传导到压电陶瓷片上。
结果就是不论你用多大力度，出来的都是重音。
而且这东西很贵且不好调教。

二手鼓组安装后还要根据实际反馈情况来调整音源的触发器参数。
如果你原声鼓的动态不熟悉还保持错误的反馈练习，容易练出错误的力度控制。
但是对于玩玩而已其实还好。

### 电子鼓品牌与型号扫盲

#### 罗兰

TD型号从1-50均有，但是并不是按照数字高低来衡量优良，没有规律可言

大致为：

| 代际              | 旗舰级 | 高级  | 中级         | 入门级            |
| ----------------- | ------ | ----- | ------------ | ----------------- |
| 一代：1997年前    |        |       | TD-5、TD-7   |                   |
| 二代：1997-2003年 | TD-10  | TD-8  | TD-6、TD-6V  |                   |
| 三代：2004-2011年 | TD-20  | TD-12 | TD-9、TD-9k2 | TD-3、TD-4、HD-1  |
| 四代：2012-2015年 | TD-30  | TD-25 | TD-15        | TD-1、TD-11、HD-3 |
| 五代：2016-2021年 | TD-50  | TD-27 | TD-17        | TD-07             |

TD-12S的技术指标：

- 动态：6层，能展现爵士鼓艺术的最低值；
- 五鼓四镲：能完成所有音乐风格的最标准配置；
- 军鼓和通鼓：双触发，带轻音边击和重音边击；
- 吊镲：镲面+镲边双触发，可止音；
- 叮叮镲：镲面+镲边+镲芯，三触发，可止音；
- 独立踩镲：镲面+镲边双触发，有Hi-Hat Splash功能；
- 首创网面底鼓；（这个不好用，底鼓击打结束鼓棒要靠在鼓面上，弹性好了停不住，费劲。而且网面容易坏。）
- 极其炫酷的Auto Sequence，至今无人能模仿，对厂商研发能力要求高。

TD-12S以当时极具开创性的配置为行业定下了标准，可以作为配置参考
如果配置与12S相同是为高级型号，标准以下即为入门、中端级，标准以上则为旗舰级或仿真级。

TD-17KV二手参考价格4k-5k
TD-17KL二手参考价格3k-3k5，配置比较拉但胜在罗兰老牌劲旅，通过慢慢拓展可以升级到不错的地步

TD-4、TD-6、TD-7、TD-8、TD-10、TD-11、TD-15、TD-20、TD-25、TD-30停产，二手老化问题可能比较重，不推荐

#### 雅马哈

作为高价低智商厂牌，音色虽然十分动听，但动态极其拉胯。22年不建议购买

型号一般命名为DTX6K-X
性价比低，价格普遍较高

#### MEDELI（美得理）/魔鲨

## 其他设备

### 降噪耳机

可以隔绝触发器的声音，听起来鼓声更纯粹

鼓赵22年推荐型号：Bose的QC35及以上型号，Sony的WH1000XM3及以上型号

### 鼓棒

Vic Firth、Tama Traditional 5A、Promark、Vater的5A型号皆可。

### 底鼓踏板

推荐单独购买，能练习标准的脚感
推荐YAMAHA FP7210A 神锤，淘宝价650。如已经断货就推荐TAMA的HP200或HP10。

### 双踩

双踩推荐TAMA HP600DTW。因为这款踩锤不但价格低，而且反馈好，脚感标准。注意这款假货特别多，一定要去天猫或京东购买；
