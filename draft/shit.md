# 论文于普通文章

我有些疑惑， 一篇论文的构成要素到底是什么 最近shit这一国内人士创办的仿造国外sclience这类恶搞期刊的报道越来越多 人们喜闻乐见这里面竟然真有一些通俗易懂且具备些许意义的文本并津津乐道, 颇有一种, 小西天出了真大圣的感觉. 正好我也正在写论文, 也在写推文, 我很想要知道论文区别于普通文章的地方究竟在哪里?

## 论文的核心目标：生产“可验证的新知识”

普通文章和论文最本质的区别在于：

| 类型     | 目标                             |
| -------- | -------------------------------- |
| 普通文章 | 表达观点 / 讲故事 / 传播信息     |
| 学术论文 | 提出一个可被验证或反驳的知识主张 |

论文必须回答一个问题：

`“我到底发现了什么新的东西？”`

这个新东西可以是：

- 新方法
- 新数据
- 新解释
- 新模型
- 新实验结果
- 对已有研究的新验证

哪怕是综述论文，本质也是：通过系统整理文献，提出新的理解框架

而普通文章通常是：

- 观点表达
- 经验总结
- 情绪表达
- 信息传播

它们不需要对“知识体系”负责。

## 论文与文章的选题

我在写论文的时候, 常常疑惑自己的选题和入手角度, 因为需要被评判, 往往需要评估自己的题材够不够好, 够不够有价值 但是普通的文章似乎就没有这种疑虑了, 可以更加随意地发表即使已经被其他人看到过但是依旧没有被自己认知到的内容, 或者很普通地就是转载或者重复也可以. 没有强烈的推陈出新的必要

### 论文的评价标准：“是否增加了知识”

学术论文在一个非常严格的评价体系里运行。评审人在看一篇论文时，本质只问三个问题：

1. 这个问题有没有人研究过？
2. 如果研究过，你比以前多做了什么？
3. 这个“多出来的东西”有没有意义？

也就是所谓的：

- novelty（新意）
- contribution（贡献）

所以论文作者天然会陷入一个焦虑：我的东西是不是已经有人做过了？
因为一旦完全重复，理论上就没有学术贡献。

这就是为什么论文写作前要做 literature review（文献综述）：
目的不是展示你读了多少论文，而是确认一件事：
你的工作在学术地图上的位置。

### 普通文章的评价标准：“是否对读者有价值”

普通文章完全是另一套逻辑。
评价标准通常是：

- 是否有趣
- 是否清晰
- 是否有启发
- 是否有传播性

换句话说：即使内容不是新的，只要读者没见过，它仍然是有价值的。

比如：
很多科普文章其实都是在重复知识：

- 黑洞是什么
- AI如何工作

这些内容早就有人写过无数次。

但只要：

- 表达更清楚
- 结构更好
- 举例更贴近生活

它仍然可以是一篇好文章。

### 论文的“新”，其实没有你想象得那么大

很多刚开始写论文的人会误解：`论文必须发现非常惊人的东西。`
其实不是。
学术里的“新”通常非常微小。

常见的“新意”包括：

1. 新方法
例如：用一种新的算法解决旧问题。

2. 新数据
例如：以前没人统计过这个数据。

3. 新场景
例如：这个方法以前只在英文数据上验证，现在在中文数据上测试。

4. 新比较
例如：以前没人系统比较这几种方法。

5. 新解释
例如：对已有结果提出新的理论解释。

很多论文其实只是：`把一个已有问题，在一个新的条件下重新验证。`
这在学术上也算贡献。

## 中医的不科学是否也与论文体系相关

那么中医相对于西医似乎显得不那么科学的原因, 是否是因为太过于经验驱动, 许多理论都是黑盒的, 而且事关人民, 也相当难以进行验证, 这就出现了如果要讨论和反驳, 那么就必须进入对应的体系, 可是种理论本来就是生长在这样的理论体系中的, 自然没有问题 中医的内容是不是也难以写成论文?

### 为什么很多人觉得中医“不够科学”

常见的原因其实是三个：

1. 理论概念比较抽象（黑箱）
中医核心概念例如：
    - 气
    - 阴阳
    - 五行
    - 经络
    - 上火
    - 湿气
这些概念有一个特点：很难直接观测或量化。
而现代医学（西医）尽量使用：
    - 可以测量的指标
    - 可以检测的物质
    - 可以观察的结构
例如：
    | 中医概念 | 西医对应方式                |
    | -------- | --------------------------- |
    | 气虚     | 可能对应代谢状态 / 免疫状态 |
    | 上火     | 可能对应炎症反应            |
    | 经络     | 尚无明确解剖结构            |
这就导致一个问题：
中医理论很多时候像一个解释系统，而不是一个可测量系统。

2. 可重复实验难度大
现代医学很强调一种研究方法：`随机对照试验（RCT）`或者可以叫做 `双盲实验`
例如研究一种药：随机分两组
    - 一组吃药
    - 一组吃安慰剂
统计疗效差异
但中医治疗有几个特点：
    - 辨证论治（每个人用药不同）
    - 方剂组合很多
    - 医生经验差异大
这样就很难设计严格的统一实验。

3. 理论体系自洽

你提到的一个观察其实很接近哲学中的一个概念：`“理论框架依赖”`
意思是一个理论在自己的体系内部通常是自洽的。
例如：
    - 经济学模型
    - 精神分析理论
    - 中医理论
如果你完全进入这个框架，它往往可以解释很多现象。
但问题在于：是否可以被外部证据检验。
现代科学特别强调：`可证伪性（Falsifiability）`, 理论必须允许被证伪。

### 中医是不是就不能写论文？

例如在期刊：

Chinese Journal of Integrative Medicine
Journal of Traditional Chinese Medicine

以及数据库：

PubMed
CNKI

都能看到大量中医研究。

但这些论文通常采用三种方式。

1. 临床统计研究例如：
研究对象：200名失眠患者
实验：
    - A组：中药治疗
    - B组：安慰剂
观察：
    - 睡眠时间
    - 入睡时间
    - 睡眠质量评分
这种方法其实完全符合现代医学论文结构。

2. 成分研究（现代药理）
例如研究某种中药:
    - 有哪些化学成分
    - 是否抗炎
    - 是否抗氧化
例如: 黄芩, 人参
很多研究会分离出：黄酮类, 皂苷类, 多糖
然后做细胞实验。

3. 经验总结研究
这是中医论文中比较常见的一种：
例如：某名医治疗糖尿病的经验总结
本质类似：案例研究, 医案分析
但这种论文在国际医学界影响力通常较小，因为证据等级比较低。

### 真正困难的地方

中医论文的困难点其实是：
理论与实验之间的转换。

例如：
如果论文说：“此药可以补气”

在现代科学框架中就必须回答：
补气具体指什么指标？
血氧？
ATP代谢？
免疫细胞？

如果不能转换成可测指标，论文就很难成立。
