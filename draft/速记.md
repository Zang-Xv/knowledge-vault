# 速记

感觉自己如果不理解内容就难以进行记录
该问题在话务培训也展露过，我会习惯性开始理解场景，使用场景来辅助记忆和理解
但如果我没法了解场景的话，我就需要尽可能快速无损的记录下来，好让我后续能够再度分析。

时长会听到有人说记重点（例如上学上课的时候）但是压缩文本内容意味着我需要了解讲话背景，如果了解讲话背景的话我可以直接领悟要点
我的速记使用背景就是在听不懂的时候可以快速抄录，以便后面对比翻看。

录音拍照当然是最佳的无损记录方式，但是如果不能使用的话，就得锻炼一下手写速记和电脑速记了。

## 中文手写速记

### 正式理论

正式的速记方法往往是使用音素符号等等来简化笔画，或者简化拼写发音（拼音速记），并通过连写加快书写方式
看起来跟密码一样，十分难懂，也需要背诵记忆许多内容
并不适用我现在的情况

### 个人符号速记

可以使用省略，简写，符号混用的技巧
打造相对易懂的个人符号体系
而且富有过渡性

最简单的方式就是通过草书来进行
可以学习部分草书的构词方法来进行简写，加上各类简化字合体字加快记录速度
通过长时间学习之后就可以笔走龙蛇了，大概吧。

#### 二简字

| 正字   | 可用速记 | 适合记录的例子       | 评价                         |
| ------ | -------: | -------------------- | ---------------------------- |
| 舞     |       午 | 舞台→午台、任务→午？ | 单字容易混，固定词中可用     |
| 圆     |       元 | 圆形→元形、圆满→元满 | 很好写，但会与“元”混淆       |
| 预、豫 |       予 | 预计→予计、预约→予约 | 实用度较高                   |
| 籽     |       子 | 种籽→种子            | 本身已有不少人这样写         |
| 蓝、篮 |       兰 | 蓝色→兰色、篮球→兰球 | 高频、明显省笔画             |
| 龄     |       令 | 年龄→年令            | 曾经相当常见，辨识度高       |
| 稀     |       希 | 稀少→希少            | 上下文一般能认出             |
| 熄     |       息 | 熄火→息火            | 很适合记录                   |
| 萧     |       肖 | 萧条→肖条            | 适合个人笔记                 |
| 座     |       坐 | 座位→坐位            | 极省笔画，但正式文本不能混用 |
| 嘴     |       咀 | 嘴巴→咀巴            | 字形较陌生，适合固定使用     |
| 戴     |       代 | 佩戴→佩代、戴帽→代帽 | 省得很多，但歧义较大         |
| 傅     |       付 | 师傅→师付            | 固定词中容易还原             |
| 签     |       佥 | 签字→佥字            | 适合会议记录，但要先熟悉“佥” |
| 胸     |       匈 | 胸口→匈口            | 比较直观                     |
| 颜     |       彦 | 颜色→彦色            | 笔画减少明显                 |
| 集     |       亼 | 集合→亼合            | 字形简单且关联性较强         |
| 矮     |       仦 | 矮小→仦小            | 字形有“小”的提示             |
| 叮咛   |     丁宁 | 叮咛→丁宁            | 适合整词替换                 |
| 吩咐   |     分付 | 吩咐→分付            | 适合整词替换                 |
| 霹雳   |     辟历 | 霹雳→辟历            | 不算高频，但容易理解         |
| 蚯蚓   |     丘引 | 蚯蚓→丘引            | 属于整词简写                 |
